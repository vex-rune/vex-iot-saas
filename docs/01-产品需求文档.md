# 产品需求文档（PRD）

> 本文档基于 [`README.md`](../../README.md) 顶层建设大纲重写，覆盖产品目标、技术约束、角色权限、功能需求、非功能需求。

---

## 1. 文档概述

### 1.1 产品目标

搭建一套面向工业 PLC / 边缘网关的**设备监控与运维平台**，围绕"接入 → 配置 → 采集 → 监控 → 控制 → 报警 → 报表"的完整链路，提供：

- 多设备统一接入与在线管理
- 点位级数据采集、转换、实时监控与远程控制
- 基于规则的报警监测与多渠道通知
- 历史数据查询、报表导出、可视化看板
- 系统级配置、权限隔离、操作审计

支撑现场无人值守、远程集中运维的工业物联场景。

### 1.2 技术约束

| 项 | 约束 |
|----|------|
| 系统形态 | 前后端分离；后端 Spring Boot 单体，双实例 + Nginx 负载均衡 |
| 设备通信 | MQTT 协议（EMQX Broker，支持双 MQTT 模式） |
| 主数据库 | MongoDB（非关系型） |
| 时序数据 | 必要时引入时序库（InfluxDB / TDengine 等，选型待定） |
| 后端技术栈 | Java 17 + Spring Boot 3.x + Spring Security + JWT |
| 前端技术栈 | React 18 + TypeScript + Vite + Ant Design 5 |
| 部署 | 阿里云 ECS 两台（负载均衡 + 应用），证书 + DNS + 域名 |
| 通知 | 短信 + 微信（公众号 / 企业微信） |
| 存储归档 | OSS 冷数据归档（超期历史数据压缩归档） |

### 1.3 用户角色定义

| 角色 | 定位 | 主要职责 |
|------|------|---------|
| **超级管理员** | 系统所有者 | 全部功能，包括租户、角色、字典等系统级配置 |
| **管理员** | 租户 / 业务管理员 | 设备、点表、报警、通知人、报表等业务级配置 |
| **操作人员** | 一线运维 | 查看设备、监控点位、对合法点位下发控制指令 |
| **访客**（可选） | 只读用户 | 仅查看，不允许任何写操作 |

> 角色模型与多租户隔离为平台级能力，详见后续章节。

## 2. 核心功能需求

### 2.1 账号与权限

| 项 | 说明 |
|----|------|
| 登录注册 | 账号密码登录，支持短信验证码；JWT 无状态认证 |
| 角色权限模型 | RBAC，菜单级 + 接口级 + 业务级三层权限控制 |
| 多租户隔离 | 数据按租户隔离；设备、点表、报警等数据严格归属 |
| 操作审计日志 | 关键写操作（配置变更、控制下发、报警确认）全量记录，可查询 |

### 2.2 设备管理

| 项 | 说明 |
|----|------|
| 设备档案 | 设备名称、编号（VEX-xxxxxx）、描述、所属网关、启用/禁用 |
| 设备分组与标签 | 支持多级分组、按标签筛选 |
| 设备拓扑 | 网关 → 设备的层级关系展示 |
| 设备状态 | 实时在线 / 离线状态、上下线事件、最近心跳时间 |
| MQTT 接入信息 | ClientID、上报 Topic、下发 Topic、用户名、密码 |

### 2.3 设备配置

| 项 | 说明 |
|----|------|
| Modbus 主站配置 | 端口号、数据位、停止位、校验位、超时、重试等 |
| MQTT 主站配置 | 服务器地址、端口、用户名、密码、ClientID、Topic |
| 数据采集配置 | 轮询时间间隔、数据格式、点位寄存器 |
| 配置版本管理 | 配置变更生成版本号，可对比差异 |
| 配置下发历史 | 记录每次下发时间、版本、操作人、结果 |
| 配置回滚 | 一键回滚到任一历史版本 |

### 2.4 点表管理

| 项 | 说明 |
|----|------|
| 点位定义 | 寄存器类型（M、Q、VD、VW 等）、地址偏移、位偏移、数据类型 |
| 数据类型 | BIT / UINT16 / FLOAT 等 |
| 读写权限 | 只读 / 可读可写（控制模块强制校验） |
| 正向公式 | PLC 原始值 → 页面显示值，支持 `round()`、四则运算、`$a` 占位 |
| 反向公式 | 页面输入值 → PLC 写入值 |
| 批量操作 | 点位批量导入 / 导出 |
| 点位命名规范 | 全局统一命名，避免重复与歧义 |

### 2.5 数据展示

| 项 | 说明 |
|----|------|
| 实时数据 | 设备所有点位最新值，含原始值 + 公式转换后展示值 |
| 历史数据 | 按设备 / 点位 / 时间范围查询，支持曲线展示 |
| 可视化看板 | 曲线、仪表盘、地图等可视化组件，支持自定义布局 |
| 数据筛选 | 时间范围、聚合方式（均值 / 最大 / 最小）、死区过滤 |

### 2.6 点位控制

| 项 | 说明 |
|----|------|
| 控制权限 | 仅"可读可写"点位允许下发（前端隐藏 + 后端二次校验） |
| 开关量控制 | 远程置位 / 复位 |
| 数值量控制 | 远程修改下发值 |
| 反向公式转换 | 输入值经反向公式生成 PLC 写入值 |
| 控制日志 | 操作人、点位、下发值、时间、结果全量可追溯 |

### 2.7 通知人管理

| 项 | 说明 |
|----|------|
| 通知人档案 | 姓名、手机号、微信 OpenID、所属部门 |
| 通知渠道开关 | 短信通知开关、微信通知开关独立配置 |
| 通知人分组 | 支持按部门 / 角色分组，便于报警规则批量关联 |

### 2.8 报警配置

| 项 | 说明 |
|----|------|
| 报警规则引擎 | 阈值条件（gt / lt / eq / 区间 / 表达式）、持续时间 |
| 报警级别 | 警告 / 严重 / 紧急，多级配置 |
| 报警关联 | 关联设备、点位、通知人 / 通知组 |
| 报警触发 | 数据异常自动触发，重复抑制机制 |
| 故障恢复 | 数值回到正常范围自动记录恢复事件 |
| 报警确认与升级 | 支持人工确认，超时未确认自动升级通知 |
| 报警历史统计 | 按设备 / 点位 / 时间 / 状态查询，统计图表 |
| 通知渠道 | 短信 + 微信双渠道，结果可追溯，支持重试 |

### 2.9 报表导出

| 项 | 说明 |
|----|------|
| 导出格式 | Excel、PDF |
| 报表模板 | 模板化管理，支持自定义字段、样式 |
| 定时报表 | 按日 / 周 / 月自动生成并推送 |
| 导出历史 | 历史导出任务记录，可重新下载 |

### 2.10 系统配置

| 项 | 说明 |
|----|------|
| 字典管理 | 通用字典维护（下拉、枚举、状态等） |
| 单位管理 | 物理量单位、量纲转换 |
| 协议字典 | Modbus 寄存器类型、数据类型、公式函数等协议相关字典 |
| 系统参数 | 平台名称、Logo、登录页等基础配置 |

### 2.11 接口与协议

| 项 | 说明 |
|----|------|
| API 文档 | Swagger / OpenAPI 自动生成 |
| 国际化 i18n | 前后端多语言支持 |
| MQTT 主题规划 | 上行 / 下行 / 心跳 / 报警主题分层命名 |
| MQTT ACL | 设备 / 用户 / 应用三级访问控制 |
| 设备协议报文 | JSON 报文结构统一约定，含设备编号、时间戳、点位数据 |

## 3. 非功能需求

### 3.1 性能需求

| 项 | 指标 |
|----|------|
| 设备数据实时性 | MQTT 上报延迟低，点位数据秒级更新 |
| 负载能力 | 双实例负载均衡，支持多设备并发、多用户在线 |
| 并发处理 | 多设备同时上报不阻塞，报警检测实时响应 |
| 数据写入 | 死区过滤：数据无变化不写入，预计减少 30%-70% |
| 历史查询 | 千万级数据按 `(deviceId, timestamp)` 复合索引，亚秒级响应 |

### 3.2 安全需求

| 项 | 说明 |
|----|------|
| 权限隔离 | 管理员 / 操作人员 / 访客严格分级，禁止越权 |
| 控制安全 | 只读点位强制拦截控制指令，避免误操作导致设备故障 |
| 通信安全 | MQTT 协议稳定通信，TLS 加密可选；服务端无状态 |
| 认证安全 | JWT 无状态认证，密钥环境变量注入 |
| 数据隔离 | 多租户数据隔离，防止越权访问 |
| 操作审计 | 所有关键操作可追溯 |

### 3.3 可用性需求

| 项 | 说明 |
|----|------|
| 高可用部署 | 双实例 + Nginx 负载均衡，单实例故障不影响整体运行 |
| 消息可靠 | 报警消息支持重试推送，保障异常可达 |
| 断线重连 | MQTT 客户端内置断线自动重连 |
| 数据持久 | 业务数据、报警记录、点位历史全量持久化 |
| 数据备份 | MongoDB 定时备份，OSS 冷数据归档 |

### 3.4 可维护性需求

| 项 | 说明 |
|----|------|
| 环境分层 | 开发 / 测试 / 预发 / 生产 四套环境独立 |
| 数据库版本 | Flyway / Liquibase 等工具管理 schema 变更 |
| 测试体系 | 单元测试 + 集成测试 + 设备模拟器 |
| 运维手册 | 部署、升级、扩容、故障恢复完整流程文档 |
| 监控告警 | 服务存活、CPU / 内存 / 磁盘、应用异常统一监控 |

### 3.5 部署与运维

| 项 | 说明 |
|----|------|
| 容器化 | Docker / Docker Compose 部署（待定） |
| CI/CD | 自动化构建、镜像推送、滚动部署 |
| NTP | 全网设备 / 服务器时间同步 |
| 防火墙 | 最小化端口开放，安全组策略明确 |
