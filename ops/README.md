# Vex 云物联 - 部署与运维配置

本目录汇总部署、运维相关配置与脚本,与 `service/`、`app/` 解耦。

## 计划文件

```
ops/
├── nginx/
│   ├── nginx.conf          # Nginx 主配置(负载均衡 + HTTPS)
│   └── conf.d/             # 站点配置
├── docker/
│   ├── docker-compose.yml  # 一键启动(开发/生产)
│   └── service.Dockerfile  # Spring Boot 镜像
├── scripts/
│   ├── deploy.sh           # 部署脚本
│   ├── archive-history.sh  # 历史数据归档
│   └── backup-mongo.sh     # MongoDB 备份
├── systemd/
│   └── iot-saas.service    # systemd 单元(无容器部署)
└── prometheus/
    └── alerts.yml          # 监控告警规则
```

## 部署拓扑(参考 README)

```
ECS-1 (2C4G)
  - Nginx (负载均衡 + 静态前端 + HTTPS)
  - EMQX MQTT Broker

ECS-2 (2C4G)
  - SpringBoot ×1 实例(双实例第二台另行部署)
```

## 环境变量清单

| 变量                         | 说明              |
| -------------------------- | --------------- |
| `MONGO_URI`                | MongoDB 连接串     |
| `REDIS_HOST/PORT/PASSWORD` | Redis 连接        |
| `JWT_SECRET`               | JWT 密钥(>=32 字节) |
| `JWT_EXPIRE`               | Token 过期时间(秒)   |
| `MQTT_BROVER`              | EMQX Broker 地址  |
| `MQTT_USER/PASSWORD`       | EMQX 凭证         |
| `MQTT_CLIENT_PREFIX`       | 客户端 ID 前缀       |
