## 基础建设

设备: 根据实际若干
- PLC: 主要是控制逻辑
- 边缘网关: Modbus 主站, 轮训采集数据并上报到 MQTT 服务器

云服务器1:
- Nginx: 负载均衡, 2核4G + 40GB系统盘
- EMQX MQTT: 用于设备与云平台的通信, 支持双 MQTT 模式

云服务器2:
- Java服务: 用于处理设备数据, 提供 API 接口
- Web前端: 用于用户交互, 展示设备数据

MongoDB数据库

其他:

- 服务器内网互通
- 数据备份策略
- 日志存储与归档
- 时序数据库(选型)
- 服务器与应用监控
- 容器化方案
- CI/CD 流程
- NTP 时钟同步


## 功能建设 (不包含硬件)

### 边缘网关功能

配置:
- Modbus 主站: 配置 Modbus 主站的参数, 如端口号、数据位、停止位、校验位等
- MQTT 主站: 配置 MQTT 主站的参数, 如服务器地址、端口、用户名、密码等
- 数据采集: 配置数据采集的参数, 如轮训时间间隔、数据格式等

约定格式:
- 约定设备编号格式, 如 "VEX-123456" 表示设备编号为 "VEX-123456" 的设备
- 提前定义好数据格式, 如 JSON 格式
- 数据采集时, 按照约定格式格式化数据


### 云服务器1功能

配置:
- Nginx: 配置 Nginx 的参数, 如监听端口、代理端口、负载均衡等
- EMQX MQTT: 配置 EMQX 的参数, 如服务器地址、端口、用户名、密码等


### 云服务器2功能

配置:
- Java服务: 配置 Java 服务的参数, 如监听端口、数据库连接等
- Web前端: 配置 Web前端的参数, 如监听端口、数据库连接等
